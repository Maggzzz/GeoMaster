# GeoMaster v2 – Fase 3 (quiz)

Utgangspunkt: testet GeoMaster v2 fase 1–2.

## Endringer
- Egen oppstartsmeny for Flaggquiz og Hovedstadquiz.
- Valg av kategori (Alle, seks verdensdeler, Annet) og vanskelighetsgrad.
- Enkel: kjente/befolkningsrike steder innen valgt kategori; Middels: blandet utvalg; Vanskelig: sjeldnere steder og nærere distraktorer.
- Ren spillvisning med oppgave og fire svaralternativer, poeng og neste-spørsmål.
- Hovedstadquiz viser nå landnavn, ikke flagg.
- Eksisterende lokal statistikk og repetisjonsmodus beholdes.
- Oppdatert service worker-cache til geomaster-v2-phase3.

## Test på Live Server
1. Fra Hjem, åpne Flaggquiz. Første skjerm skal være oppstartsmenyen.
2. Test Alle / Middels. Start, svar, neste, avslutt, prøv igjen.
3. Test også Afrika, Nord-Amerika, Oseania og Annet på Lett / Middels / Vanskelig.
4. Start Hovedstadquiz og sjekk at landnavn vises (ikke flagg).
5. Bekreft Statistikk -> Repetisjon og eksisterende Kart/Utforsk.
6. Test på mobil. Ikke push til main før kontroll er ferdig.
